# M1 A model any source can feed

reef's model already has a clean seam: anything that makes a list of nodes can build the checked
graph. What sits above it, rendering markdown, resolving doc links and taking a why or a what from
a doc, reads files. This milestone moves that work behind a source a server can provide. It also
gives nodes names that hold across projects and plans, and lets the model say what is ready and
why the rest waits. None of it needs shoal, so it can start now.
