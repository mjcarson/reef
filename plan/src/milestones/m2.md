# M2 The shoal store

reef's projects, plans and nodes in shoal, built against its `ScanSupport` branch. Shoal there
has no client table scans yet, no secondary indexes and no transactions. The layout works within
those limits: listing partitions with known keys, each node's spec as one serialized field,
versions checked by conditional writes, and plan revisions made current by one pointer write.
Shoal can't migrate a table yet either. reef ignores that while it is in development, and a
schema change may need a fresh data directory. [X1](../design/architecture.md#shoal-in-the-build) and
[X2](../design/store.md#rows-and-versions) gate all of it.
