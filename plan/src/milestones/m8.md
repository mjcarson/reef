# M8 Claude fed from the terminal

The loop in the user's own Claude Code session. next_task hands Claude the next node by the
user's queue. Claude plans it in plan mode, the user answers its questions and approves the plan,
and Claude implements it and marks it done. Claude then resolves any open comments, and the Stop
hook clears the context and starts the next node. [X4](../design/feed-loop.md#the-terminal-loop) proves the pieces
first.
