# M5 The user's order of work

Whether a node is ready still comes from its `needs`. Among ready nodes, the user's queue decides
what Claude takes next. The queue is per project and spans its plans; a loop can be narrowed to
one plan. The CLI sets the order first, so the terminal loop can use it before the app's queue
panel lands.
