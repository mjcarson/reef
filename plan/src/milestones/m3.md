# M3 One service, two front doors

One service layer owns shoal and the model. Two front doors call it: the JSON API, for the CLI,
the MCP server and the hook, and the app's server functions ([M4](m4.md)). The CLI and the MCP
tools are what the terminal loop runs on, so this milestone does not wait for the app.
