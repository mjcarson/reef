# M7 Code tied to its node

Each node keeps the diff that did its work. Commits are squashed regularly, so reef reads git
only to capture a node's changes, by a Claude Code hook as soon as the node is done, and stores
them itself. The user comments on the changed lines.
[X3](../design/code-and-comments.md#capturing-a-nodes-changes) decides how one node's changes are
picked out while several are worked on at once, and gates all of it.
