# M4 reef-app, the UI in Dioxus

The app: a project and plan picker, the plan's graph, a node panel that edits the node and holds
its changes and comments, and live refresh while Claude works. The graph is the existing viewer,
mounted inside a component. Porting it to native Dioxus is optional, later work.
[X6](../design/app.md#the-viewer-inside-the-app) gates all of it.
