    status: done
    docs: [../design/app.md#what-x6-found]
    description:
      why: "A viewer whose element is removed keeps its closures, observers and `document` listeners, and draws its detached element again on a filter change, so each remount leaks one."
      what: "Dropping the handle, or an unmount through it, disconnects the viewer's observers and listeners, so the app can remount a view per plan or route."
      details: "Every listener the view and its charts add, and both observers, go in a `Wiring` the handle owns, apart from the view their closures hold. Dropping the handle, or `Handle::unmount`, takes each listener off, disconnects the observers and drops the closures, which frees the view, then empties the element so it can be drawn into again; a view busy with an event is emptied once the event is done. `mount_all`'s views last as long as their page, so their wiring is kept for good, as before."

# M4 reef-app, the UI in Dioxus

The app: a project and plan picker, the plan's graph, a sidebar whose tabs show the node and edit
it, and later hold its changes and comments, and live refresh while Claude works. The graph was
first the existing viewer, mounted inside a component
([X6](../design/app.md#the-viewer-inside-the-app), which gates all of it), and is now drawn by
Dioxus itself ([C55](../design/app.md#the-canvas-in-dioxus)).
